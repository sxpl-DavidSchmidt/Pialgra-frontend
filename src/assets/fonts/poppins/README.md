# Poppins

Vendored from @fontsource/poppins 5.3.0:
https://registry.npmjs.org/@fontsource/poppins/-/poppins-5.3.0.tgz

Includes only the normal weights used by the frontend: 400 (regular), 600 (semibold), and 700 (bold). All three supplied Unicode subsets (Latin, Latin Extended, and Devanagari) are retained to preserve character coverage for user-entered text. Unused weights and italic styles are omitted.
WOFF2 files are served locally by Vite; no font provider is contacted at runtime.
